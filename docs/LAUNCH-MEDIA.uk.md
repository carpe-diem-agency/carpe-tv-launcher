## Кадри для Threads і README

1. Головна: відкритий природний фон, улюблені плитки й фокус пульта.
2. Бібліотека: відкриття з лівого меню, пошук, рівні тіні карток.
3. Налаштування вигляду: вибір фонів і рекомендоване затемнення.
4. Власна заставка: повноекранне фото, без системних вікон.
5. За можливості — один кадр на телевізорі, щоб було видно масштаб з дивана.

Для README достатньо перших трьох чистих ADB-скрінів 1920×1080. Перед зйомкою
перевір, що APK і скрін відповідають одному commit/versionCode. Не змінюй
роздільність зображення під виглядом нативного 4K.

## Коротке відео з приставки, 25–35 секунд

- 0–4 с: Home, фон і годинник.
- 4–10 с: плавний перехід по улюблених плитках.
- 10–18 с: бібліотека, один запит у пошуку, запуск програми.
- 18–24 с: фізична кнопка Home, фокус повертається до щойно відкритої програми.
- 24–30 с: вибір фону або заставка, фінальний кадр із назвою Carpe TV.

Запис — `screenrecord` на тестовому стіку, без мікрофона та системного коду
налагодження. За бажанням окремо знімається телевізор на телефон, щоб показати
плавність руху, яку запис екрана може передати неточно.

## Чернетка для Threads

> Роблю Carpe TV — легкий лаунчер для Android TV та Google TV. Хотілось
> домашній екран, де програми одразу під рукою, пульт відчувається природно,
> а фон можна змінити під себе. Зараз перевіряю його на Xiaomi TV Stick.
> Підготував бібліотеку програм, пошук, заставку й повернення до штатного Home.
> Ось кілька кадрів із приставки. Код і APK будуть тут після завершення
> релізної перевірки: https://github.com/carpe-diem-agency/carpe-tv-launcher
