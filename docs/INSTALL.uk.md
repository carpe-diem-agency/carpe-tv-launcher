# Встановлення, Home та відкат

[English](INSTALL.md) · **Українська** · [README](../README.md)

## Перед початком

- Android TV / Google TV, Android 8.0 (API 26) або новіший. Системні дії перевірено
  лише на Xiaomi TV Stick `MiTV-AFMU1` з Android TV 14 — [матриця пристроїв](../README.md#де-перевірено).
- Штатний лаунчер залишиться встановленим. Не видаляй його й не очищай його дані.
- Функції відрізняються між версіями APK. Перед додатковими системними діями
  нижче звір примітки до свого релізу.
- Системне керування підтримує основного користувача Android 0. Root не потрібен.

## 1. Встановити Carpe TV

**Без комп’ютера:** відкрий на телевізорі
[сторінку Carpe TV](https://carpe-diem-agency.github.io/carpe-tv-launcher/)
й натисни **Завантажити APK**. Якщо на приставці немає браузера, завантаж APK
з тієї самої сторінки на телефон і передай файл на телевізор. Для приймання
файлу деяким приставкам потрібна окрема програма з Google Play.

Зараз сторінка показує лише попередній перегляд: кнопка завантаження стане активною
після публічного релізу. [GitHub Releases](https://github.com/carpe-diem-agency/carpe-tv-launcher/releases)
буде запасним джерелом того самого APK.

1. Відкрий завантажений APK на телевізорі. Якщо Android запропонує вибір
   програми, обери **«Програма встановлення пакета»**. На [Android 8+](https://developer.android.com/studio/publish#install-unknown-apps) дозволь встановлення
   **саме браузеру або файловому менеджеру**, що відкрив файл, й підтвердь
   системний запит. Дозвіл для Carpe TV на майбутні оновлення — окремий.
2. Запусти Carpe TV зі списку програм. Обери **Спершу оглянути**, перевір
   бібліотеку, відкриття програм і пульт. Пункт **Зробити головним екраном**
   одразу відкриває системний вибір Home.

Carpe TV для базових функцій потребує **один APK**. Shizuku, ADB, root і
комп’ютер для першого запуску не потрібні. Звір назву файлу, версію й SHA-256
зі сторінкою релізу; APK з іншим підписом не оновить встановлений Carpe TV.

Якщо на пристрої вже є персональна тестова збірка, вона має інший ідентифікатор
пакета. Публічний APK встановлюється **окремою програмою**: спочатку перевір її,
тоді обери Home. Персональна збірка залишиться доступною для повернення.
Наступні публічні релізи оновлюватимуть публічну програму без перевстановлення,
якщо підпис збігається і номер версії зростає.

**Для розробників — встановлення через ADB:**

```sh
adb devices
adb -s DEVICE_SERIAL install -r carpe-tv.apk
adb -s DEVICE_SERIAL shell am start -n agency.carpediem.tv/agency.carpediem.tv.prototype.MainActivity
```

`DEVICE_SERIAL` — твій ідентифікатор з `adb devices`, не адреса нашого тестового стіка.
Не видаляй попередню версію для обходу помилки підпису: потрібен сумісний APK.
Debug-збірки з різних комп’ютерів/CI можуть мати різні підписи.

## 2. Налаштувати Home

1. На першому запуску натисни **Зробити головним екраном** або пізніше відкрий
   Carpe TV → **Налаштування → Пристрій → Зробити головним екраном**.
2. У системному виборі обери **Carpe TV**.
3. Відкрий іншу програму й натисни фізичну кнопку Home. Перевір ще раз після перезапуску.

Деякі прошивки ігнорують стандартний вибір Home. Публічна збірка не містить
служби спеціальних можливостей для перехоплення Google TV; якщо Home не працює,
не вимикай штатний лаунчер до перевірки окремого способу повернення.

## 3. Підключити Shizuku за бажанням

Shizuku — окремий застосунок для системних команд без root. Carpe TV використовує
його для сну за таймером і керування окремими системними програмами. Саме
встановлення Shizuku нічого не вимикає. Головний екран, запуск програм, вибір
Carpe TV як Home і перегляд стану пакетів працюють без нього. Код на екрані
Android потрібен лише для першого підключення; це не пароль від Google чи Carpe TV.

1. Установи Shizuku з [офіційного джерела](https://shizuku.rikka.app/download/).
2. Увімкни «Налагодження через Wi-Fi» у параметрах розробника Android. Телефон і
   приставка мають бути в одній **довіреній** мережі Wi-Fi.
3. Відкрий **Carpe TV → Налаштування → Пристрій → Системні дії**,
   обери **«1. Підключити через телефон»** і скануй QR-код телефоном. Локальна сторінка
   активна 15 хвилин; не пересилай її адресу чи код іншим. Після п’яти
   невдалих спроб сесія закривається — запусти майстер знову.
4. На приставці відкрий **Налагодження через Wi-Fi → Підключити пристрій за кодом**.
   Шість цифр введи лише на сторінці телефона. Після повідомлення **Paired** повернися
   до Carpe TV. Парування виконується один раз, доки Android його не скине.
5. Пультом обери **«2. Запустити Shizuku»**. У запиті Shizuku надай доступ Carpe TV,
   якщо погоджуєшся. Перевір статус системного доступу перед змінами.

На Xiaomi `MiTV-AFMU1` перевірено парування через телефон та повторний запуск
Shizuku кнопкою Carpe TV; на інших прошивках поведінка потребує перевірки.
Локальна сторінка працює через HTTP, тому використовуй її лише в довіреній мережі.

Дозвіл можна відкликати в Shizuku. Після перезавантаження без root знову ввімкни
«Налагодження через Wi-Fi» за потреби та натисни **«2. Запустити Shizuku»**;
на нашому стіку попередній дозвіл Carpe TV зберігся. Без працюючого Shizuku
модуль показує стан, але не виконує системні зміни. Уже вимкнений пакет залишається вимкненим.

## 4. Вимкнути аналітику Xiaomi

Перед зміною системного пакета збережи робочий APK і перевірений спосіб
повернення до штатного Home. APK не є повним бекапом приватних даних.

1. Відкрий **Налаштування → Програми й фон → Аналітика Xiaomi**.
2. Якщо вже бачиш **«Вимкнено»**, більше нічого робити не треба.
3. Обери **Вимкнути аналітику**. Перевір у попередженні пакет `com.miui.tv.analytics`.
4. Прочитай наслідки. **Скасувати** залишає стан без змін; **Продовжити** виконує дію.
5. Дочекайся підтвердження та стану **«Вимкнено»**. Якщо результат не підтверджений,
   натисни **Оновити стан**, не вважай пакет вимкненим лише через натискання кнопки.
6. Перевір стан після перезавантаження. На тестовому стіку пакет залишився вимкненим,
   його процес і активні служби були відсутні.

Перед зміною увімкненого пакета Carpe TV зберігає попередній стан. Дані не видаляються.
Напис «Увімкнено» означає стан пакета, не доказ того, що він зараз працює у фоні.

Щоб повернути аналітику: запусти Shizuku → відкрий ту саму картку → **Увімкнути /
відновити аналітику** → прочитай попередження → підтвердь. Відновиться збережений стан.
Якщо пакет вимкнули поза Carpe TV й запису немає, дія явно вмикає його; початковий
стан не вигадується. Після цього аналітика знову зможе працювати у фоні.

## Повернення до штатного лаунчера


### Якщо штатний лаунчер увімкнений

Відкрий **Налаштування → Пристрій → Вибрати інший лаунчер** або
**Програми й фон → Вибрати інший лаунчер**. Обери штатний Home у системному
вікні й перевір фізичну кнопку Home. Для цього Shizuku не потрібна.

### Якщо Google TV вимкнений на Xiaomi

1. Переконайся, що Shizuku працює й доступ дозволений.
2. **Налаштування → Програми й фон → Увімкнути Google TV й вибрати Home**.
3. Прочитай попередження та підтвердь. Модуль вмикає пакет Google TV, перевіряє
   результат і відкриває системний вибір Home. Якщо закрити вибір, поточний
   домашній екран залишиться без змін.
4. Обери **Google TV**. Саме натискання «Відновити» ще не змінює системний вибір Home.
5. Натисни фізичну кнопку Home. Перевір після перезапуску перед видаленням Carpe TV.

Повернення до Google TV кнопкою Home перевірено на нашому стіку.
Якщо Shizuku недоступний, модуль нічого не змінює; запусти його або використай ручний шлях.

### Без Shizuku

Якщо Google TV вже ввімкнений, вибери його в Android **Програми → Типові програми →
Головний екран**.
Назви пунктів залежать від прошивки. Збережи доступ до Carpe TV, поки не перевіриш Home.

### Якщо Carpe TV не відкривається — ADB

Ці команди призначені для перевіреного Google TV-пакета на нашому Xiaomi Stick.
На інших приставках спершу встанови точну назву штатного пакета; не копіюй її навмання.
Потрібне раніше налаштоване ADB-підключення; Shizuku для цього не потрібний.

```sh
adb devices
adb -s DEVICE_SERIAL shell pm enable --user 0 com.google.android.apps.tv.launcherx
adb -s DEVICE_SERIAL shell am start -a android.settings.HOME_SETTINGS
```

Обери Google TV у відкритому системному вікні.
Якщо прошивка не має екрана HOME_SETTINGS, скористайся її власними параметрами Home.

Цей шлях не видаляє дані, не перевстановлює APK й не виконує скидання пристрою.

## Знову повернути Carpe TV

1. Відкрий Carpe TV зі списку програм. Якщо потрібно:

```sh
adb -s DEVICE_SERIAL shell am start -n agency.carpediem.tv/agency.carpediem.tv.prototype.MainActivity
```

2. Повтори вибір Carpe TV для Home з кроку 2.
3. Перевір Home з іншої програми. У тесті штатний лаунчер лишився встановленим.

## Повне вимкнення Google TV — обмеження цієї прошивки

На Xiaomi `MiTV-AFMU1` із перевіреною збіркою вимкнення `com.google.android.apps.tv.launcherx`
відкрило `com.google.android.tungsten.setupwraith/.RecoveryActivity` замість Carpe TV.
Повторне призначення Home це не виправило; пакет одразу ввімкнули назад.

Тому **інструкції вимкнення Google TV тут немає**, а модуль містить лише його ввімкнення.
Не вимикай майстер налаштування/відновлення чи невідомі системні служби заради обходу.
Старий Xiaomi Home `com.mitv.tvhome.atv` уже був вимкнений до цього тесту — це не
рекомендація для інших стіків. Інші моделі потребують окремої перевірки й відкату.

## Оновлення та старий APK

[Оновлення, дозволи й скріншоти](UPDATING.uk.md). Звір канал і підпис конкретного релізу.
APK зі старішим versionCode може бути відхилений Android навіть із тим самим підписом.
Не видаляй поточну програму лише для примусового downgrade: це може втратити її налаштування.
