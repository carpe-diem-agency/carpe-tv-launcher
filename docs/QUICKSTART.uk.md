# Carpe TV: швидке встановлення

**Статус:** інструкція для майбутнього публічного релізу. Поки репозиторій приватний,
APK доступний лише запрошеним користувачам. Опис збірки й підпису звіряй на сторінці
конкретного релізу.

1. На приставці відкрий [останній реліз](https://github.com/carpe-diem-agency/carpe-tv-launcher/releases/latest)
   і завантаж `carpe-tv.apk`. Якщо браузера немає, передай цей файл із телефона.
2. Відкрий APK. Якщо з’явиться вибір програми, обери **«Програма встановлення
   пакета»**. Підтвердь встановлення; якщо Android запитає дозвіл, надай його
   браузеру або файловому менеджеру, що відкрив файл.
3. Запусти Carpe TV. Обери **Спершу оглянути** або **Зробити головним екраном**.
   Для Home вибери Carpe TV у системному вікні, відкрий іншу програму й перевір
   кнопку Home на пульті.

Базовому лаунчеру достатньо одного APK; спосіб доставлення файла залежить від
приставки, а для передавання з телефона може знадобитися окрема програма.
Shizuku потрібна лише для додаткових системних дій. Пізніше вибір Home доступний
у **Налаштування → Пристрій → Зробити головним екраном**. Деякі прошивки ігнорують
цей вибір. Перевір Home ще раз після перезапуску й не видаляй штатний лаунчер.
Якщо потрібно повернутися, відкрий **Налаштування → Пристрій → Вибрати інший
лаунчер** і вибери штатний головний екран.
