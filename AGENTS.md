# Carpe TV working instructions

- Use Ukrainian when communicating with the project owner.
- Keep the English and Ukrainian interfaces aligned.
- Keep the public application ID and update feed consistent with the release documents.
- Do not change the Android Home role or device system settings in P1/P2 checks.
- Do not merge or publish a release without an owner request.
- Follow the release and verification steps in `docs/RELEASING.md`.
- Do not add `Co-authored-by:` trailers to commits or squash merges.
