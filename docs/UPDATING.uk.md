# Оновлення Carpe TV

## 1. Відкрий екран оновлень

**Налаштування → Про лаунчер → Оновлення**. Натисни **Перевірити**, потім
**Завантажити**. Після старту можна повернутись до інших програм — файл завантажує
системний DownloadManager. Коли APK перевірено, з’явиться **Встановити**.


## 2. Першого разу дай дозвіл Android

Кнопка **Дозволити встановлення** відкриває системні налаштування. У списку знайди
**Carpe TV** і ввімкни **«Встановлювати невідомі додатки» / «Дозволити із цього джерела»**.
Дозвіл потрібен лише Carpe TV.


Шлях перевірено на Xiaomi Android TV 14. На іншій приставці назви й розташування
можуть відрізнятися. Лаунчер сам не вмикає цей дозвіл. Якщо автоматично не відкрилось,
знайди встановлення невідомих додатків у спеціальному доступі програм / безпеці Android.

## 3. Повернись та встанови

Натисни **Назад**, повернись у **Оновлення**, знову натисни **Встановити**,
після цього — системне **Оновити**. Якщо скасувати, стара версія залишається працювати.


Під час інсталяції лаунчер коротко закриється. Після неї натисни Home і перевір
версію. У перевіреному оновленні обране, фон, затемнення, анімації та мова збереглися.
Резерв попереднього APK й налаштувань зберігається приватно; це не повний дамп.

Канал оновлень через GitHub підготовлено; він запрацює після першого публічного
стабільного релізу. Попередній тест через локальний сервер не доводить роботу
майбутнього публічного завантаження.
