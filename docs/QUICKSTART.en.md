# Carpe TV: quick install

**Status:** the source is public, but the stable APK is still being prepared.
Use these steps after a signed release appears. Check its version and checksum
on that release page.

1. On your TV, open the [latest release](https://github.com/carpe-diem-agency/carpe-tv-launcher/releases/latest)
   and download `carpe-tv.apk`. If there is no browser, transfer the file from your phone.
2. Open the APK. If Android asks which app to use, choose **Package Installer**.
   Confirm installation; if Android asks for permission, grant it to the browser
   or file manager that opened the file.
3. Open Carpe TV. Choose **Explore first** or **Make Home**. To use Home, select
   Carpe TV in Android's picker, open another app, then test the remote's Home button.

The basic launcher needs one APK. Shizuku is optional for extra system controls.
You can choose Home later in **Settings → Device → Make Home**. Some firmware
ignores the choice. Test Home again after reboot and keep the stock launcher installed.
To return, open **Settings → Device → Choose another launcher** and select the
stock Home app.
